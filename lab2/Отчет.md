# Задание 1

## Задача 2
### Текст задачи
Человек. Создайте сущность Человек, которая описывается: имя — строка; рост — целое число. Может возвращать текстовое представление вида "Name, рост: height", где Name и height — это переменные с именем и ростом. Необходимо создать и вывести на экран следующих людей: человек с именем «Клеопатра» и ростом 152; человек с именем «Пушкин» и ростом 167; человек с именем «Владимир» и ростом 189.

### Алгоритм решения
Сущность описана классом Human с двумя полями: имя хранится строкой, рост — целым числом. Конструктор принимает оба значения и записывает их в поля создаваемого объекта; слово this нужно, чтобы отличить поле от параметра с тем же именем. Метод toString переопределён и склеивает имя, текст ", рост: " и рост в одну строку. В main создаются три объекта и по очереди передаются в println, который сам вызывает у них toString. Без переопределения на экран вывелось бы служебное имя класса с хеш-кодом вида `lab2.Human@1b6d3586`, а не описание человека.

## Задача 3
### Текст задачи
Имена. Создайте сущность Имя, которая описывается тремя параметрами: фамилия, личное имя, отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трёх параметров: Фамилия Имя Отчество (например, "Иванов Иван Иванович"). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду. Необходимо создать следующие имена: Клеопатра; Пушкин Александр Сергеевич; Маяковский Владимир. Обратите внимание, что при выводе на экран не заданные параметры никак не участвуют в образовании строки.

### Алгоритм решения
Класс Names хранит три строковых поля: фамилию, имя и отчество. Чтобы не передавать каждый раз все три значения, сделано три конструктора: только с именем, с фамилией и именем, со всеми тремя частями. Короткие конструкторы сами ничего не присваивают, а через `this(...)` вызывают полный и передают null вместо недостающих частей — так присваивание полей написано в одном месте. Метод toString начинает с пустой строки и проверяет поля по порядку: фамилия, имя, отчество. Если поле задано (не равно null), оно дописывается в строку, а после фамилии и имени ставится пробел-разделитель. Незаданные части просто пропускаются. Если отчества нет, в конце остаётся лишний пробел — его убирает метод trim().

# Задание 2

## Задача 4
### Текст задачи
Сотрудники и отделы. Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в котором сотрудник работает, причём у каждого отдела есть название и начальник, который также является Сотрудником. Сотрудник может быть приведён к текстовой форме вида "Имя работает в отделе Название, начальник которого Имя". В случае если сотрудник является руководителем отдела, текстовая форма должна быть "Имя начальник отдела Название". Необходимо выполнить следующие задачи: создать сотрудников Петрова, Козлова, Сидорова, работающих в отделе IT; сделать Козлова начальником IT-отдела; вывести на экран текстовое представление всех трёх сотрудников (у всех троих должен оказаться один и тот же отдел и начальник).

### Алгоритм решения
Сделаны два класса, которые ссылаются друг на друга: у сотрудника (Employee) есть имя и ссылка на отдел, у отдела (Department) — название и ссылка на начальника, который тоже сотрудник. Начальника нельзя передать в конструктор отдела: сотруднику при создании уже нужен отдел, значит, отдел появляется раньше всех сотрудников. Поэтому сначала создаётся отдел без начальника, затем три сотрудника, и только после этого начальник назначается методом setHead. Все сотрудники хранят ссылку на один и тот же объект отдела, поэтому назначенный начальник сразу виден у всех троих. В toString сотрудник сравнивает себя с начальником отдела через `==`, то есть проверяет, один ли это и тот же объект: если да, выводится форма для начальника, иначе — обычная, где имя начальника берётся из отдела. У отдела тоже есть свой toString, он выводит начальника и название отдела.

Сотрудники и отделы. Измените решение, полученное в задаче 2.4, таким образом, чтобы, имея ссылку на сотрудника, можно было бы узнать список всех сотрудников этого отдела.

### Алгоритм решения
По условию каждая задача оформляется в своих классах, поэтому доработанная версия задачи 2.4 сделана в отдельных классах Employee34 и Department34. В отдел добавлен список сотрудников (ArrayList) и метод addEmployee, который кладёт в него сотрудника. Заполнять список вручную не нужно: сотрудник сам добавляет себя в свой отдел прямо в конструкторе, передавая в addEmployee ссылку this на только что созданный объект. Метод сотрудника getDepartmentEmployees переходит по ссылке в его отдел и возвращает список оттуда. В итоге, имея только ссылку на Козлова, можно получить всех сотрудников отдела IT, включая его самого; в main этот список обходится циклом for-each и выводятся имена.

Создаём Имена. Измените сущность Имя из задачи 1.3. Новые требования включают: имя можно создать, указав только личное имя; имя можно создать, указав личное имя и фамилию; имя можно создать, указав все три параметра: личное имя, фамилию, отчество. Необходимо создать следующие имена: Клеопатра; Александр Сергеевич Пушкин; Владимир Маяковский; Христофор Бонифатьевич (здесь Христофор — это имя, а Бонифатьевич — фамилия).

### Алгоритм решения

# Задание 5

## Задача 1
### Текст задачи
Пистолет стреляет. Создайте сущность Пистолет, которая описывается следующим образом: имеет количество патронов (целое число); может быть создан с указанием начального количества патронов; может быть создан без указания начального количества патронов, в этом случае он изначально заряжен пятью патронами; может стрелять, что приводит к выводу на экран текста «Бах!» в том случае, если количество патронов больше нуля, иначе делает «Клац!». После каждого выстрела (когда вывелся «Бах!») количество патронов уменьшается на один. Создайте пистолет с тремя патронами и выстрелите из него пять раз.

### Алгоритм решения
Класс Pistol хранит количество патронов в целочисленном поле. Конструкторов два: первый принимает начальное число патронов, второй, без параметров, вызывает первый через `this(5)` — поэтому пистолет по умолчанию заряжен пятью патронами. Метод shoot сначала проверяет, остались ли патроны: если их больше нуля, печатается «Бах!» и счётчик уменьшается на единицу; иначе печатается «Клац!», а счётчик не меняется, поэтому в минус уйти не может. В main пистолет с тремя патронами стреляет в цикле пять раз: первые три выстрела дают «Бах!», последние два — «Клац!», и после этого toString показывает 0 патронов. Чтобы проверить второй конструктор, создаётся ещё один пистолет без параметров — у него 5 патронов.
